Leaving paid models behind.

What if the useful part of an AI product was the orchestration, not the recurring model bill?

The expensive part of an AI workflow is often not the answer. It is the repeated context, routing, waiting, and tool execution around the answer.

Every request does not need the largest model. Short transformations can run locally. A repository-wide refactor may benefit from stronger reasoning. A command that changes a file should execute on the computer where the file lives.

Thomas AI separates those concerns in a native Rust gateway for Apple Silicon, combining local MLX inference with a carefully controlled pool of free NVIDIA endpoints.

A two-lane architecture

The local lane uses MLX-LM and Apple Silicon unified memory. The hosted lane uses free NVIDIA endpoints when more reasoning is needed. A Rust gateway sits between them and owns routing, streaming, health checks, metrics, and tools.

Easy requests can use local MLX or Nemotron Bolt. Normal requests use Nemotron Lightning. Difficult requests use a verified free strong endpoint. Current in-flight load is part of the decision, so routing does not blindly send every request to one backend.

What “free” actually means

“The API lists the model” is not the same as “the endpoint is free and usable.” NVIDIA’s catalog distinguishes free endpoints from other offerings, and accounts can have different availability.

Free by policy, not by assumption.
Thomas AI uses an explicit allowlist of catalog-verified free endpoint IDs. Configuration can narrow the list, but it cannot add an unverified paid model.

That makes the budget predictable: local requests use local compute, and hosted requests stay inside the free pool. Quotas and endpoint failures are surfaced through health checks, fallback routing, and metrics instead of hidden behind a paid fallback.

Cloud reasoning, local action

A hosted model cannot directly touch a Mac. Thomas AI supplies a tool bridge. Free Nemotron receives tools for reading files, inspecting Git, running commands, and writing code; the Rust gateway executes those tools locally.

user request → free planner → local Rust tool → tool result → final answer

The stronger model reasons about the task while the computer that owns the repository performs the action. Full-access mode is intentional and should only run on a trusted Mac account.

The result: an AI system you can explain

Replacing paid model dependencies is not only a cost decision. It changes the product into a control plane where routing, model choice, latency, failures, and load are visible.

Thomas AI also supports SSE token streaming, so compatible clients see responses as they arrive. Local MLX and free NVIDIA routing are working today; EXO/RDMA is the future multi-Mac integration point.

Build the control plane once.
